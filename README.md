## Niels Karel Snooij

I build small models that read DNA.

Next to every number I put the simplest method that could give the same answer.
Usually that method is counting. On marine novelty detection, counting
four-letter words still ties my 257 million parameter model. I publish that too.

**[EH14 X](https://github.com/bioxcompute/eh14x)** reads marker genes and
environmental DNA. It does one thing better than the tool people actually use:
it tells a real read from a PCR artefact. 0.9735 against 0.9442 for UCHIME on
the same set.

One route is switched off. It scored below guessing on human variants, so it
answers 410 Gone instead of a number.

**[dark-taxa-novelty](https://github.com/bioxcompute/dark-taxa-novelty)** is the
benchmark I measure on. 1,760 sequences, forty taxa held out, and the baseline in
one numpy file so you can beat it yourself.

I also design peptide genes from biosynthetic clusters. None of them has been in
a lab yet.
